# 8-Week Study Roadmap

| Week | Topics | Practice / deliverable |
|---|---|---|
| 1 | setup, syntax, types, input/output | calculator and unit converter |
| 2 | operators, conditions, loops | number games and pattern printing |
| 3 | functions, recursion, arrays | statistics for a list of values |
| 4 | strings and pointers | safe string utilities; pointer tracing |
| 5 | structs, enums, dynamic memory | student/contact records |
| 6 | files, preprocessing, bit operations | persistent text-based address book |
| 7 | searching, sorting, linked lists | implement and test common algorithms |
| 8 | interview bank, debugging, projects | finish one project and explain its trade-offs |

Daily session (45–75 min): 10 min review, 20 min new idea, 20–40 min coding, 5 min notes. Revisit a topic after one day, one week, and one month.
