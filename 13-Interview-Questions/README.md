# Interview Questions

Open `INTERVIEW-QUESTIONS.md` for the full 250-question bank. Each question includes an answer, a separately saved C source file, and output. The code folder has one source file per question. Compile any example with `gcc -std=c11 -Wall -Wextra -Wpedantic Q001.c -o demo`.

Tip: first answer out loud without looking at the answer. Then compile the code, change a boundary case, and explain what would differ on another implementation.
